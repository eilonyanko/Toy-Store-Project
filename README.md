# Toy Store Management Project

A comprehensive management system for a toy store developed in C. This project demonstrates the application of core programming concepts including dynamic memory allocation, data structures, and file management. Features include inventory tracking, sales processing, and automated data persistence.

## Key Features
* **Inventory Management:** Add, update, and remove items from the store database.
* **Search Functionality:** Find items by ID, name, category, etc.
* **Sales Processing:** Manage transactions and update stock levels.
* **Data Persistence:** Save and load store data from files.
* **Memory Efficiency:** Use of dynamic memory allocation and structs.

## Technical Skills
* **Language:** C
* **Data Structures:** Structs, Dynamic Arrays, Linked Lists and Binary Search Trees.
* **File I/O:** Reading and writing to binary and text files.
* **Pointers:** Manual memory management (malloc/free).
